# Zanderio: Case Study

Frontend and integration work on the partner portal for [Zanderio](https://zanderio.ai), an AI sales agent for ecommerce stores. The source code is proprietary and private, so this page describes what I built and how, without sharing any company code or client data.

**Product:** https://zanderio.ai  |  **My role:** Frontend and API integration developer  |  **Stack:** Next.js, React, REST APIs

![Zanderio public website](screenshot.png)

*Zanderio's public website, shown for context. The partner portal itself is behind a login and contains client data, so it is not shown here.*

## Overview
Zanderio's partners needed a portal to manage their work with the platform. I built the portal's frontend, connected it to backend services, and delivered interface features to the specific requirements of clients.

## What I built
- **Partner portal frontend:** Designed and implemented the portal UI in Next.js and React, using reusable components and responsive layouts.
- **API integration:** Worked on REST APIs and connected the frontend to them, including request handling, loading and error states, and data validation.
- **Email integration:** Initiated and implemented an email integration that lets the platform connect with clients automatically.
- **Forms, buttons, and modals:** Built custom forms, buttons, and modal dialogs to client-specified requirements, with input validation and consistent behavior across the portal.
- **Client collaboration:** Turned client requests into working features, working alongside backend developers and reviewing changes through pull requests.

## Skills demonstrated
Next.js, React, REST API integration, form handling and validation, reusable component architecture, email integration, building features from client requirements.

## Note on the code
The repository is private by design to protect the company's intellectual property and its clients' data. I'm happy to walk through the architecture, my decisions, and my contributions in an interview.
